# ADRs

Este directorio es el destino canonico de las decisiones tecnicas. La
coleccion historica permanece en [`../history/DECISIONS.md`](../history/DECISIONS.md)
mientras se migran sus entradas sin perder trazabilidad.

Cada ADR debe incluir contexto, decision, alternativas, archivos afectados,
validacion, riesgo residual y rollback.

Decisiones vigentes recientes:

- [ADR-040: CI y contrato de runtime](ADR-040-ci-runtime.md).
- [ADR-041: adapters AWS-compatible](ADR-041-aws-compatible-adapters.md).
- [ADR-042: Floci externo como entorno dev](ADR-042-floci-dev-mocks.md).

Las decisiones anteriores permanecen consultables en el historico y no deben
interpretarse como una descripcion mas nueva que `docs/ARCHITECTURE.md`.
